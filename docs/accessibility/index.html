Website accessibility

Information that is easier to use.

This website aims to make public cricket information clear and usable with a keyboard, screen reader, larger text or a smaller screen.

Practical features

The site includes a skip-to-content link, structured headings, descriptive image text and visible keyboard focus. You can use keyboard controls for navigation, expand the FAQ answers and change the news and fixture views. There is no autoplay audio or video.

Use the view that works for you

Use your browser’s zoom and text controls to enlarge the page. The layout is designed to reflow on smaller screens. The website’s text-size and high-contrast preferences are optional display settings, not a request for personal information.

Our accessibility target

The accessibility target is WCAG 2.2 AA. Full conformance has not been independently certified. Manual review with NVDA, JAWS, VoiceOver and TalkBack is still needed; automated checks alone cannot establish accessibility for everyone.

External pages and feedback

Facebook and other linked websites have their own accessibility features and may require an account. If a page is difficult to use, a general enquiry can identify the page and the barrier without including medical or other sensitive details.
