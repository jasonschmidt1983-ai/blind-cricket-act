Albury program

Regional cricket. Local connection.

A regional development focus that brings local players and coaches into the blind cricket community.

Building consistency in the region

The Albury program focuses on local players and coaches, with consistent summer training as a program aim. It provides a regional starting point for people interested in blind cricket.

Check the current arrangements

Session dates, venues, coaching contacts and availability have not yet been published here. Ask Blind Cricket ACT for the current Albury program details before making travel plans.
